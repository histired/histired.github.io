Privacy policy

Last updated 9 October 2026

Maple is a personal assistant that runs only on her developer's own computer, for that one person. This page explains what Google user data she accesses and what happens to it.

What Maple accesses

  • Google Calendar events (calendar.events): Maple reads the events on the user's primary calendar to answer questions about their schedule and to give spoken reminders at the times the calendar specifies. She creates an event only after showing it to the user and receiving an explicit yes.
  • Sending email (gmail.send): Maple sends an email only after showing the full message to the user and receiving an explicit yes. She has no permission to read, search or delete email.

Where it goes

  • All processing happens on the user's own computer. The language model Maple uses runs locally; Google data is not sent to any AI service or other third party.
  • The sign-in token is stored only on that computer, in a file readable only by the user.
  • Calendar details shown on screen, and a short local list of the reminders Maple has spoken, stay on that computer. They are not uploaded anywhere.
  • Google data is never sold, shared, or used for advertising.

Limited Use

Maple's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time from the Google Account's third-party connections page. Deleting the local token file has the same effect on Maple's side.

Contact

Questions about this policy can be raised on this site's GitHub page.
